# 🧮 Scientific Calculator

A modern and responsive **Scientific Calculator** built using **HTML, CSS, and JavaScript**. This calculator supports both basic arithmetic operations and advanced scientific functions, making it suitable for students, developers, and anyone who needs quick mathematical computations.

---

## ✨ Features

### 🔢 Basic Arithmetic
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Percentage
- Decimal calculations
- Parentheses support
- Clear (`AC`) and Delete (`DEL`) functions

### 📐 Scientific Functions
- sin(x)
- cos(x)
- tan(x)
- log(x)
- √ Square Root
- x² Square

### 🎨 User Interface
- Responsive design
- Clean and modern UI
- Smooth button animations
- Keyboard support
- Mobile-friendly layout
- Dark theme interface

---

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & Responsive Design
- **JavaScript (ES6)** – Calculator Logic

```bash

```

### 2. Navigate to the project

```bash

```

### 3. Open the project

Simply open `index.html` in your browser.

Or use VS Code Live Server.
